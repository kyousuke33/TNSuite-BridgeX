# TNSuite BridgeX

TNSuite BridgeX is a Windows x64 secure file-transfer desktop application independently derived from FileZilla Client 3.70.6 and adapted for TNSuite.

**Accepted product baseline:** `v0.5 Build12-Hotfix16`.

This repository is being bootstrapped into governed canonical source. Until the exact Hotfix16 source tree is imported and the bootstrap PR is merged, `main` is not yet the BridgeX source authority.

Read `AGENTS.md` and `docs/90_GOVERNANCE/CURRENT_STATE.md` before changing source, CI or release behavior.

BridgeX is independent and is not affiliated with or endorsed by the FileZilla Project. See `LICENSE`, `COPYING` and `NOTICE.md`.
