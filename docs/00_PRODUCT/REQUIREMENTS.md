# Requirements
- Windows x64.
- FileZilla Client 3.70.6 derived core with attribution/licensing preserved.
- wxWidgets 3.3.3 / MSYS2 UCRT64 build baseline.
- Light/Dark and EN/VI persistence.
- SFTP/transfer functionality and bounded CLI.
- Clean install/upgrade/uninstall.
- No secrets embedded in client.
- Future updates are optional to users and governed through RCP/Portal.
