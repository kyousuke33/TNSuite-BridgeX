BridgeX diagnostic checklist

Before reporting a BridgeX-specific issue, collect the information below. Never include passwords or private-key contents.

1. Version

Open Help → About and note the BridgeX build number and FileZilla core version.

2. CLI runtime

BridgeX-CLI.exe --selftest --json
BridgeX-CLI.exe doctor --json

3. Reproduction

Record the exact action, expected result, actual result, and whether the issue occurs in Light mode, Dark mode, or both.

4. Transfer issue

Include protocol (FTP/FTPS/SFTP), server port, and the non-secret status/error messages shown by BridgeX. Redact hostnames/IPs when necessary.

5. Privacy

Do not attach private keys, passwords, access tokens, session secrets, or production credentials.

This checklist is for TNSuite BridgeX. Upstream FileZilla support channels are not used for BridgeX-specific modifications.
