TNSuite BridgeX

Secure Transfer & Automation

BridgeX combines a desktop FTP/FTPS/SFTP transfer client with an independent SFTP automation CLI.

Connect

Use Sites for reusable connections. Use the connection strip for a one-off session. SFTP uses port 22 unless the server is configured differently.

Transfer files

The left pane is local storage and the right pane is the remote server. Drag files between panes or use the context menu. The transfer queue at the bottom shows active, failed and successful transfers.

Automation CLI

Open Automation → Open BridgeX CLI, then run:

BridgeX-CLI.exe --help
BridgeX-CLI.exe doctor --json

Site profiles store host, user, port and key path only. Password storage is not supported by the BridgeX CLI.

Appearance & language

Open Settings → Interface. BridgeX supports English and Vietnamese, plus Light and Dark themes. Restart BridgeX after changing either setting.

Security

Host-key checking is strict by default in BridgeX CLI. Do not disable host-key verification for production systems.

Upstream attribution

The BridgeX GUI is based on FileZilla Client open-source code. Upstream copyright and license information remains available from the About dialog.
